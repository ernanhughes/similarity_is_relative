## Confirmed remediation findings

### Folded interval ranking score

The interval score is non-monotone in support. A maximally ambiguous interval and a confidently resolved interval can receive the same ranking score. Therefore the published interval risk–coverage curves cannot be used for matched-coverage conclusions.

### Direct-conformal curve prediction defect

The direct conformal implementation records prediction-set membership as a class prediction outside singleton accepted sets. Its selective singleton metrics remain descriptive, but its ranked curves must be recomputed from fixed estimator argmax predictions.

### Fold-preprocessing leakage

The primitive Ridge alpha search fits `StandardScaler` before repository-grouped folds. Fold validation repositories therefore influence model-selection preprocessing. C0-D will fit preprocessing inside every training fold.

### Discrete boundary mass

The primitive targets are integer counts and the queries use strict thresholds at fit medians. In v1, 2,380 of 4,110 iteration rows lie exactly on at least one primitive threshold. The frozen labels remain defined, but the current boundary and regime interpretation is inadequate.

### Missing accepted-class composition

The conjunction has only 268 positive rows among 4,110. Every corrected selective diagnostic must report true/false class composition and error type, not only aggregate accepted rows and risk.

### Unmeasured cross-role contamination risk

Whole-repository name separation does not by itself establish absence of exact source duplicates, normalized-AST duplicates, forks, mirrors, generated templates or repository-family overlap. PR D1 will audit these before corrected replay.
